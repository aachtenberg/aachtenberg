# Hi, I'm Andrew 👋

**Technical Lead, SRE & AI @ BMO.** 20+ years in infrastructure and databases.

I build tools where AI does the legwork and a human keeps the merge button: database review, alert triage, PR review, and flood monitoring for my own stretch of river.

## 📌 Projects

### [🔍 Second Look](https://github.com/aachtenberg/secondlook)
Snapshots a database, compares it with a normal moment, and writes a short review of what changed and how to fix it. Oracle, PostgreSQL, MySQL/MariaDB, SQL Server.

### [🤖 CFOperator](https://github.com/aachtenberg/cfoperator)
Self-hosted AI SRE agent. Triages alerts, investigates, and opens a GitOps fix PR. It never touches a live cluster.

### [🧐 agent-review](https://github.com/aachtenberg/agent-review)
AI pull request reviewer for GitHub Actions. Follows each change to the code that uses it. Costs cents per review.

### [🌊 Ottawa River Freshet](https://github.com/aachtenberg/ottawa-river-freshet)
Community flood monitoring for the Ottawa River, plus a public case file testing whether spring flood peaks changed after 2017. Live at [freshet.xgrunt.com](https://freshet.xgrunt.com).

### [📚 Dynatrace DQL Knowledge Base](https://github.com/aachtenberg/dynatrace-dql-kb)
Reference docs, Copilot agents, and a RAG pipeline so LLMs write DQL that actually runs.

### [🔌 snowq](https://github.com/aachtenberg/snow-query)
Query ServiceNow's REST APIs by reusing an SSO browser session. No API user needed.
